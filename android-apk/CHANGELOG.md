# История Android-приложения

## v4 — 0.4.1-mobile, versionCode 4 (21.11.2026) — текущая

- **Проверка ComfyUI при подключении**: приложение находит студию, запрашивает
  `/api/state` и не открывает интерфейс, пока ComfyUI на ПК не запущен. Показывает
  «ComfyUI не запущен на компьютере» и кнопку «Повторить».
- **Обновления для телефона**: в «Настройки → Обновление» проверяется
  `android-apk/version.json` (сервер `/api/android/update`, затем GitHub напрямую).
  Жёлтая стрелка в шапке появляется только для новой версии телефона; обновления
  ПК на телефоне не показываются. Кнопка «Скачать и установить» скачивает APK и
  открывает установщик (нужно разрешение «Установка неизвестных приложений»).
- Карточка «С телефона» удалена; кнопка APK, адрес для телефона и брандмауэр
  перенесены в «Обновление».
- APK подписан тем же debug-ключом, `versionCode 4` ставится поверх 3.

## v3 — 0.4.0-mobile, versionCode 3 (21.11.2026) — предыдущая

Тонкий клиент студии. Это версия в этой папке.

- Приложение находит **SpriteAnim Studio на ПК** и открывает её интерфейс;
  вся работа (ComfyUI, модели, файлы) — на компьютере.
- Поиск сделан по образцу рабочего ComfyPult:
  - UDP 8190 (`SPRITEANIM-DISCOVER-1`) на `255.255.255.255`, широковещательные
    адреса своих подсетей, DHCP-broadcast и типовые подсети точек доступа
    (`192.168.43/42/137`, `172.20.10`, `192.168.0/1`, `10.0.0/1`);
  - если broadcast не проходит — перебор этих же подсетей по TCP 8189
    (64 потока, 200 мс на адрес, до 12 с) с проверкой `/api/net`.
- Экран подключения: ручной адрес, «Найти компьютер в сети», недавние адреса.
- При ошибке связи приложение само возвращается на экран и запускает поиск.
- Скачивания: `DownloadManager` + мост для `blob:` (PNG листа, JSON, zip),
  имена файлов берутся из ссылки, если в разметке нет `download`.
- Выбор файлов из галереи, микрофон, «экран не гаснет».
- Размер 0,86 МБ (без встроенного Python).

Серверные изменения, без которых APK не работает:

- `GET /api/net` отдаёт `app: "spriteanim-studio"`, порт, адреса, `urls`;
- UDP 8190 отвечает на запрос, первым отдаёт адрес из подсети отправителя;
- доступ по LAN (`settings.json → lan`) **включён по умолчанию**;
- `/api/file` понимает `Range` (видео на телефоне);
- мобильная вёрстка (≤700 px) и `?tab=`;
- карточка «С телефона»: статус брандмауэра и кнопка открытия портов
  (TCP 8189, UDP 8190, локальная подсеть);
- `/api/android/apk` — раздача APK со страницы настроек.

## v2 — 0.3.3-mobile, versionCode 2 (20.11.2026) — отменена

Попытка сделать телефон полностью независимым от ПК: в APK встроили CPython
(Chaquopy 17.2, Python 3.15) и весь `server.py` с интерфейсом и воркфлоу.

- Размер 39,9 МБ.
- Приложение искало **ComfyUI** на порту 8188, но ComfyUI по умолчанию слушает
  только `127.0.0.1` и из сети недоступен — на телефоне ничего не находилось.
- Требовала настройки ComfyUI (`--listen 0.0.0.0`) и не давала полной парности
  (агент, голос, редактор Godot/Unity оставались на ПК).
- Отменена в пользу тонкого клиента, как в рабочем ComfyPult.

## v1 — 0.3.3, versionCode 1 (20.11.2026)

Первый тонкий клиент: WebView студии, простой UDP-поиск и перебор своей /24.
Доступ по LAN был выключен по умолчанию, поэтому без настройки телефон ничего
не находил. Заменён на v3 с поиском как в ComfyPult и LAN по умолчанию.
