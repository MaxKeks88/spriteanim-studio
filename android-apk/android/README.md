# SpriteAnim Studio для Android

Тонкий клиент: приложение находит **студию на компьютере** в локальной сети и
открывает её интерфейс. Вся работа — ComfyUI, модели, файлы, история — остаётся
на ПК. Так же устроен рабочий ComfyPult: на ПК запускается агент, телефон его
находит.

```
телефон: [экран подключения + WebView]  ──HTTP──▶  ПК: SpriteAnim Studio :8189
                                                      └──▶ ComfyUI :8188
```

## Что нужно на компьютере

1. Запустить **SpriteAnim Studio** (`Запуск.vbs` или установленную программу).
2. ComfyUI — как обычно, на `127.0.0.1:8188`. **Выставлять ComfyUI в сеть не
   нужно**: с ним общается студия на ПК.
3. В студии: **⚙ Настройки → С телефона** — доступ включён по умолчанию. Если
   написано «брандмауэр: порт закрыт», нажмите **«Открыть в брандмауэре»** и
   подтвердите запрос Windows (один раз).

Телефон и компьютер должны быть в одной сети: обычный Wi-Fi, точка доступа с
телефона или Wi-Fi с компьютера — подходит любой вариант.

## Как подключиться

1. Установите APK: `Install\SpriteAnimStudio-Android.apk`.
2. Откройте приложение. Оно сразу начнёт искать студию:
   - UDP-запрос по Wi-Fi и типовым подсетям точки доступа;
   - если ответа нет — перебор адресов подсети на порт 8189 (до 12 с).
3. Если нашло — откроется интерфейс; адрес запомнится.
4. Если нет — нажмите **«Найти компьютер в сети»** ещё раз, проверьте
   брандмауэр или введите адрес вручную: студия показывает его в
   **Настройки → С телефона** (например, `192.168.43.100:8189`).
5. Недавние адреса показываются кнопками на экране подключения.

При ошибке связи приложение само возвращается на экран подключения и запускает
поиск заново. «Назад» → «Другой компьютер» — сменить ПК.

## Что работает

Всё, что и на ПК: «Изображения», «Убрать фон», «Анимация», «Апскейл»,
«Спрайт-лист» (включая установку в Godot/Unity), «Промпт агентом», голосовой
ввод, история, настройки, темы, RU/EN.

Загрузка картинок из галереи, скачивание видео/кадров/zip/листа в «Загрузки»
телефона, микрофон (разрешение запрашивается при первом использовании).

## Если не находит компьютер

1. Студия на ПК действительно запущена? Без неё искать нечего.
2. **Настройки → С телефона**: доступ включён, статус брандмауэра «порт открыт».
3. Телефон и ПК в одной сети (не гостевая Wi-Fi с изоляцией клиентов).
4. Введите адрес с экрана студии вручную.
5. Гостевая сеть часто режет broadcast — сработает перебор адресов или ручной
   ввод.

## Сборка

Требования: JDK 17+ (подходит `jbr` из Android Studio), Android SDK
(`%LOCALAPPDATA%\Android\Sdk`).

```bat
cd android
build-apk.bat
```

или в VS Code: **Terminal → Run Task → «Собрать APK (Android)»**.

APK: `android\app\build\outputs\apk\debug\app-debug.apk` (~0,9 МБ), debug-подпись.
Установка по USB:

```bat
"%LOCALAPPDATA%\Android\Sdk\platform-tools\adb.exe" install -r android\app\build\outputs\apk\debug\app-debug.apk
```

## Устройство

- `app/src/main/java/com/spriteanim/studio/Discovery.java` — поиск студии:
  UDP 8190 (`SPRITEANIM-DISCOVER-1`), широковещание по своим подсетям и типовым
  подсетям точек доступа, затем TCP-перебор порта 8189 с проверкой
  `/api/net` (`app: "spriteanim-studio"`). Логика повторяет рабочий ComfyPult.
- `MainActivity.java` — экран подключения (поиск, недавние, ручной адрес),
  WebView, выбор файлов, скачивания (`DownloadManager` + мост для `blob:`),
  микрофон, «Назад».
- `server.py` на ПК отдаёт `/api/net` с именем приложения и отвечает на UDP
  8190; доступ по LAN включён по умолчанию (`settings.json → lan`).
