# SpriteAnim Studio для Android — папка `android-apk`

Версия: **0.4.1-mobile**, `versionCode 4`, размер **0,89 МБ**, сборка 21.11.2026.

> **Обязательно перед запуском приложения на телефоне запустите на компьютере
> ComfyUI.** Без него телефон подключится к студии, но приложение покажет
> «ComfyUI не запущен на компьютере» и не откроет интерфейс. Это не ошибка
> приложения: вся генерация идёт на ПК через ComfyUI.

Здесь собрано всё, что относится к телефонному приложению:

```
android-apk/
├─ SpriteAnimStudio-Android-0.4.1.apk   готовое приложение
├─ version.json                         последняя версия для проверки обновлений
├─ android/                             исходники и сборка (Gradle)
├─ README.md                            этот файл
├─ BUILD.md                             как собрать APK
├─ CHANGELOG.md                         что делали и почему (v1 → v4)
└─ SERVER.md                            что должно работать на компьютере
```

## Что это такое

Тонкий клиент студии. Приложение находит **SpriteAnim Studio на компьютере** в
локальной сети и открывает её интерфейс в WebView. Вся работа — ComfyUI, модели,
файлы, история — остаётся на ПК; телефон только показывает и запускает. Так же
устроен рабочий ComfyPult: на ПК работает агент (`run.bat`), телефон находит его
по сети и открывает его интерфейс.

```
телефон: [поиск + WebView]  ──HTTP──▶  ПК: SpriteAnim Studio :8189
                                          └──▶ ComfyUI :8188 (только localhost)
```

## Что нужно на компьютере

1. **SpriteAnim Studio 0.4.0 или новее** (`Запуск.vbs`, `python server.py` или установщик).
   В версиях до 0.4.0 нет `/api/net`, UDP-поиска и доступа по LAN.
2. **ComfyUI на `127.0.0.1:8188` — обязательно.** Выставлять его в сеть не нужно:
   с ним общается студия на ПК. Приложение при подключении проверяет
   `/api/state` и не открывает интерфейс, пока ComfyUI не запущен.
3. **Настройки → Обновление**: там же кнопка **«Скачать APK»**, адрес для
   телефона и статус брандмауэра. Если написано «брандмауэр: порт закрыт» —
   нажмите **«Открыть в брандмауэре»** и подтвердите запрос Windows (один раз).
4. Телефон и ПК в одной сети: обычный Wi-Fi, точка доступа телефона или Wi-Fi
   с компьютера — подходит любой вариант.

## Установка

1. Перекиньте `SpriteAnimStudio-Android-0.4.1.apk` на телефон (проводник, облако,
   мессенджер).
2. Откройте файл и разрешите установку из этого источника.
3. Предупреждения «неизвестный источник» и «приложение не проверено» —
   **стандартные для любого APK не из магазина**, не признак вируса. Подпись у
   приложения есть (debug-ключ). Подробнее — раздел «Подпись» ниже.
4. `versionCode 4` ставится поверх предыдущей версии.

## Первое подключение

1. Запустите на ПК **ComfyUI**, затем **студию**.
2. Откройте приложение — оно ищет студию:
   - **UDP 8190**: запрос уходит на `255.255.255.255`, на широковещательный адрес
     каждой своей подсети, на DHCP-broadcast и на типовые подсети точек доступа
     (`192.168.43/42/137`, `172.20.10`, `192.168.0/1`, `10.0.0/1`);
   - если ответа нет — **перебор этих же подсетей по TCP 8189** (64 потока,
     200 мс на адрес, до 12 с) с проверкой `/api/net`.
3. Найдя студию, приложение проверяет **ComfyUI** (`/api/state`) и только потом
   открывает интерфейс. Адрес запоминается.
4. Если ComfyUI выключен — приложение покажет **«ComfyUI не запущен на
   компьютере»** и кнопку **«Повторить»**. Запустите ComfyUI и нажмите её.
5. Если не нашло студию — проверьте брандмауэр или введите адрес вручную.
   Адрес показывает студия: **Настройки → Обновление** (например,
   `192.168.43.100:8189`).
6. Недавние адреса — кнопками на экране подключения.
   «Назад» → «Другой компьютер» — сменить ПК.

## Обновления приложения на телефоне

- В студии **Настройки → Обновление** карточка показывает версию **телефонного**
  приложения и доступную версию. Обновления для ПК в этом месте на телефоне не
  показываются.
- Когда на GitHub появляется новая версия (`android-apk/version.json` с большим
  `versionCode`), в шапке приложения загорается жёлтая **стрелка**. Клик открывает
  «Обновление».
- **«Скачать и установить»** скачивает APK и открывает системный установщик.
  Android один раз спросит разрешение «Установка неизвестных приложений» для
  SpriteAnim Studio — разрешите и повторите.
- Проверка сначала идёт через сервер студии (`/api/android/update`), затем
  напрямую с GitHub, если сервер старой версии.
- APK для ПК и телефон обновляются отдельно: обновление ПК не предлагается на
  телефоне.

## Что умеет

Всё, что и версия для ПК, потому что логика выполняется на компьютере:

- «Изображения», «Убрать фон», «Анимация», «Апскейл», «Спрайт-лист»;
- установка анимаций в Godot/Unity, «Промпт агентом», голосовой ввод;
- история, настройки, темы, RU/EN;
- выбор картинок из галереи, скачивание видео/кадров/zip/листа в «Загрузки»
  телефона, микрофон (разрешение запрашивается один раз);
- экран не гаснет во время работы.

## Как ищет (для понимания)

- Сервер студии отвечает на UDP 8190 JSON-ом:
  `{"app":"spriteanim-studio","port":8189,"hostname":"…","urls":["http://…:8189"]}`.
  Первым в `urls` идёт адрес из подсети отправителя, поэтому телефон не получит
  адрес другого сетевого адаптера (виртуалки, VPN).
- Если broadcast режется роутером или телефон раздаёт точку доступа (обычный
  broadcast уходит в мобильную сеть) — приложение перебирает адреса подсетей
  напрямую и проверяет, что на 8189 действительно студия (`app` в `/api/net`).

## Ограничения

- **Студия и ComfyUI на ПК должны быть запущены.** Приложение не запускает их
  удалённо — так же, как ComfyPult не запускает свой `run.bat`.
- Гостевая Wi-Fi-сеть с изоляцией клиентов блокирует broadcast: сработает
  перебор адресов или ручной ввод.
- Очень большие спрайт-листы (сотни кадров 1024 px, апскейл ×4) упираются в
  память Android — ограничение браузерной сборки, а не APK.
- Приложение не хранит результаты: они на ПК.

## Подпись, лицензии, магазины

- APK подписан **debug-ключом** (`CN=Android Debug`). Для личной установки этого
  достаточно; приложение работает. Обновления ставятся поверх, пока ключ тот же.
- «Небезопасный источник» — предупреждение про **способ установки**, а не про
  ключ. Оно есть у любого APK вне Google Play/RuStore. Полностью убирается
  только магазином.
- Для нормальной release-подписи нужен свой keystore (см. `BUILD.md`). При смене
  ключа старую версию придётся удалить.
- Код проекта — **MIT** (см. `LICENSE` в корне репозитория); сторонние
  компоненты и модели — по своим лицензиям (`THIRD-PARTY.md`). На установку APK
  это не влияет.
- Магазины: Google Play (аккаунт $25, проверка), RuStore, F-Droid. Для личного
  инструмента не обязательны.

## Если что-то не работает

1. **ComfyUI запущен на ПК?** Приложение проверяет это при подключении и скажет,
   если он выключен.
2. Студия на ПК запущена? Открывается ли `http://127.0.0.1:8189/` на самом ПК?
3. В студии **Настройки → Обновление**: брандмауэр «порт открыт».
4. Телефон и ПК в одной сети? (Проверьте адреса: у телефона и ПК должен быть
   общий префикс сети.)
5. Введите адрес вручную с экрана студии.
6. Если не открывается даже в браузере телефона по этому адресу — дело в сети
   или брандмауэре, а не в APK.
