# Что должно работать на компьютере

APK — только клиент. Всё считает и хранит **SpriteAnim Studio на ПК**, поэтому
для телефона важна именно эта часть.

## Требования

1. Запущена студия **0.4.0 или новее** (`Запуск.vbs`, `python server.py` или
   установщик). В версиях до 0.4.0 нет `/api/net` с именем приложения, UDP-поиска
   и доступа по LAN.
2. Запущен ComfyUI на `127.0.0.1:8188` (как обычно). В сеть его выставлять не
   нужно.
3. В студии **Настройки → Обновление** доступ включён (по умолчанию да);
   при необходимости — «Открыть в брандмауэре».

## Что именно использует APK

| Что | Где в проекте | Зачем |
|---|---|---|
| `GET /api/net` | `server.py`, `net_info()` | телефон проверяет, что нашёл студию, и берёт адрес |
| UDP 8190 + `SPRITEANIM-DISCOVER-1` | `discovery_loop()` | быстрый поиск в Wi-Fi и точке доступа |
| `lan` по умолчанию | `lan_enabled()` | без него запросы с телефона получают 403 |
| `Range` в `/api/file` | `Handler._send_file`, `_proxy_view` | перемотка видео и кадры |
| мобильная вёрстка ≤700 px | `ui/index.html` | нормальный вид на телефоне |
| `?tab=img|bg|gen|up|sheet` | `ui/index.html` | открыть вкладку сразу |
| `/api/firewall`, `/api/firewall/open` | `server.py` | статус и открытие портов (UAC) |
| `/api/android/apk` | `server.py` | скачать APK со страницы настроек |
| `/api/android/update` | `server.py`, `android_update()` | последняя версия телефона из `android-apk/version.json` (`versionCode`, `versionName`, `apk`) |

Дополнительно (не обязательно для подключения): `/api/state` отдаёт `mobile`
(режим встроенного Python, сейчас не используется) и `comfy_url`.

## Быстрая проверка на ПК

```powershell
# студия запущена
Invoke-RestMethod http://127.0.0.1:8189/api/net

# поиск, как его делает телефон
python -c "import socket; s=socket.socket(socket.AF_INET,socket.SOCK_DGRAM); s.setsockopt(socket.SOL_SOCKET,socket.SO_BROADCAST,1); s.settimeout(2); s.sendto(b'SPRITEANIM-DISCOVER-1',('255.255.255.255',8190)); print(s.recvfrom(2048)[0].decode())"
```

Ожидаемо: JSON с `"app": "spriteanim-studio"` и `"urls"`, и ответ на UDP.

## Проверка с телефона

Откройте в браузере телефона `http://<адрес-пк>:8189/`. Если страница
открывается, а APK не находит — дело в поиске, а не в сети. Если не
открывается — проверьте брандмауэр и что телефон и ПК в одной подсети.

## Брандмауэр

Сеть точки доступа Windows часто считает «Общедоступной». В студии:
**Настройки → Обновление** — статус «брандмауэр: порт открыт/закрыт» и кнопка
«Открыть в брандмауэре» (добавляет TCP 8189 и UDP 8190 для локальной подсети,
`profile=any`, нужен UAC один раз).
