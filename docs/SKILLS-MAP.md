## 4. Что это значит для нас

1. **Шесть из восьми скиллов ложатся на модели, которые уже стоят**: klein, Krea 2, Qwen 2.1
   (генерация и правка), плюс два «формата результата» поверх них.
2. **`minimax-h3-image`** ждёт свою модель — держим на будущее, как и решено.
3. **`hailuo-h3`** — единственный, где важно разделять «формат модели» и «правила платформы»:
   три поля и структура промпта применимы к нашей локальной H3; лимиты 5–15 с, 7000 символов,
   водяной знак и модерация 1026/1027 — это про облако Hailuo, к локальной модели не относятся.
4. **`akterskaya-igra`** — про игру персонажа, а не про формат конкретной модели; даёт эмоции
   и микровыражения. Для видео — да; для спрайтовых циклов (ходьба/атака) — только часть
   про позы и ритм.
5. **Пробел:** под наши **спрайтовые циклы** (ходьба, атака, смерть) готового скилла нет —
   ни в этом наборе, ни у нас. Нужен свой короткий скилл (свой текст, не правка чужого):
   «одна поза = один кадр, петля, фиксированная камера, ровный фон, без камеры и эффектов».
6. **Z-Image** (`z_image_bf16`) тоже без скилла — если понадобится, пишем свой.

## 5. Как это будет подключено

Выбранная модель в студии → ровно один скилл (её) + при необходимости второй «формат результата»
(`storyboard` / `karta-personazha`). Тексты скиллов не правим — только обёртки подключения
и разбор ответа на поля (промпт, негатив, шаги, cfg, формат кадра).
