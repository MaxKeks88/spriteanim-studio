Копия скиллов из референсного приложения **Minimax H3 Workspace** (`_internal\skills`).
Скопировано 17.11.2026, по решению владельца: «скиллы должны быть у нас обязательно,
вытащить все и сохранить в проекте».

Проверка копии: 13 файлов, 173,4 КБ, SHA-256 всех файлов совпадает с источником.

## Правило

**Тексты скиллов не править.** Это чужой откалиброванный материал; наши изменения —
только обёртки (какой скилл когда подключать, какие поля вытаскивать). Если нужна
правка по существу — сначала обсудить с владельцем, потом менять и писать здесь.

## Как это будет использоваться

1. Выбран режим/модель в студии → берётся ровно один скилл (не все).
2. Скилл кладётся в system-сообщение локального агента (Gemma 4 12B через llama.cpp),
   бриф пользователя + картинка (если есть) — в user-сообщение.
3. Ответ разбирается на поля: промпт (английский), негатив, шаги, cfg, размер.
4. Пользователь видит, какой скилл сработал, и вставляет промпт кнопкой.

Длинные скиллы (28 КБ) в контекст целиком не влезут вместе с references — подключаем
только нужный файл, справочники — по запросу (см. `docs/PLAN.md`).
